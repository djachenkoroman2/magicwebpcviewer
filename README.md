# Magic Web Point Cloud Viewer

Web-приложение для просмотра, анализа и базовой обработки облаков точек.

Приложение написано на Python, использует Panel для web-интерфейса и PyVista/VTK для серверного рендеринга. Браузер показывает уже подготовленный сервером результат, а тяжелая работа с геометрией и визуализацией выполняется на стороне сервера.

## Возможности

- выбор облака точек из настроенной директории на сервере;
- загрузка новых файлов через браузер;
- опциональный voxel downsampling при загрузке;
- просмотр свойств облака: формат, размер файла, количество точек, RGB, scalar fields, bounding box, плотность;
- режимы визуализации RGB, scalar field и однотонный цвет;
- настройка размера точки, цвета фона, цвета однотонного режима и базовых видов камеры;
- очистка сцены;
- voxel downsampling открытого облака;
- скачивание результата в формате PLY;
- понятные сообщения об ошибках в интерфейсе.

## Требования

- Python 3.11 или новее;
- `uv`;
- GPU и рабочий OpenGL/VTK-рендеринг на сервере для ускоренного серверного рендера;
- для headless Linux может понадобиться системный `xvfb` или корректно настроенный EGL/OSMesa.

Python-зависимости описаны в `pyproject.toml`:

- `panel`;
- `pyvista`;
- `numpy`;
- `pillow`;
- `laspy[lazrs]`.

## Установка

Установите `uv`, если он еще не установлен:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Создайте окружение и установите зависимости:

```bash
uv sync
```

Для зависимостей разработки и тестов:

```bash
uv sync --group dev
```

## Директории данных

По умолчанию приложение использует:

- `data/clouds` - основная директория с облаками точек;
- `data/clouds/uploads` - загруженные через интерфейс файлы;
- `data/clouds/processed` - обработанные и экспортированные PLY-файлы.

Положите исходные облака точек в `data/clouds` или укажите другую директорию при запуске.

## Запуск

Базовый запуск:

```bash
uv run magicwebpcviewer
```

После запуска откройте:

```text
http://127.0.0.1:5006
```

Запуск с явными параметрами:

```bash
uv run magicwebpcviewer \
  --host 0.0.0.0 \
  --port 5006 \
  --data-dir /path/to/point-clouds \
  --max-upload-mb 1024
```

Альтернативный запуск через Panel:

```bash
uv run panel serve src/magicwebpcviewer/panel_app.py --show
```

## Остановка

Остановите сервер в терминале:

```text
Ctrl+C
```

Если приложение запущено как systemd/supervisor/docker-сервис, останавливайте его штатным способом для выбранной системы запуска.

## Параметры CLI

```text
--host                 адрес для bind, по умолчанию 127.0.0.1
--port                 порт, по умолчанию 5006
--data-dir             серверная директория с облаками точек
--upload-dir           директория для загруженных файлов
--processed-dir        директория для обработанных файлов
--max-upload-mb        лимит размера загружаемого файла
--render-width         ширина серверного рендера
--render-height        высота серверного рендера
--max-render-points    максимум точек для preview-рендера
--websocket-origin     origin для запуска за reverse proxy
--show / --no-show     открыть браузер при старте
--use-xvfb / --no-use-xvfb
                       попробовать запустить Xvfb перед рендерингом
```

## Переменные окружения

Все основные параметры можно задавать через переменные окружения:

```text
PCV_DATA_DIR
PCV_UPLOAD_DIR
PCV_PROCESSED_DIR
PCV_HOST
PCV_PORT
PCV_SHOW
PCV_USE_XVFB
PCV_MAX_UPLOAD_MB
PCV_RENDER_WIDTH
PCV_RENDER_HEIGHT
PCV_MAX_RENDER_POINTS
```

Пример:

```bash

```

## Поддерживаемые форматы

Базовая поддержка:

- `.ply`;
- `.pcd`;
- `.las`;
- `.laz`;
- `.xyz`;
- `.txt`;
- `.csv`;
- `.vtk`;
- `.vtp`.

Примечания:

- `.las` и `.laz` читаются через `laspy`; для `.laz` используется зависимость `lazrs`.
- `.ply`, `.vtk`, `.vtp` и часть `.pcd` читаются через PyVista/VTK.
- Для `.pcd` есть fallback-парсер ASCII PCD. Binary PCD зависит от поддержки VTK; если VTK не смог прочитать binary PCD, приложение покажет ошибку.
- `.xyz`, `.txt` и `.csv` ожидают числовые колонки `x y z`. Если после XYZ идут три колонки в диапазоне 0..255, они считаются RGB; остальные дополнительные колонки становятся scalar fields.

## Типовые сценарии

1. Открыть облако с сервера:
   - положите файл в `data/clouds`;
   - нажмите `Обновить`;
   - выберите файл;
   - нажмите `Открыть`.

2. Загрузить файл:
   - выберите файл в поле загрузки;
   - при необходимости включите `Даунсемплинг при загрузке`;
   - задайте `Размер voxel`;
   - нажмите `Загрузить на сервер`.

3. Включить RGB:
   - откройте облако с RGB-данными;
   - выберите режим `RGB`.

4. Выбрать scalar field:
   - откройте облако с числовыми point-data полями;
   - выберите режим `Scalar`;
   - выберите поле в `Scalar field`.

5. Выполнить даунсемплинг:
   - откройте облако;
   - задайте `Размер voxel`;
   - нажмите `Даунсемплинг`;
   - после обработки приложение покажет исходное и итоговое количество точек.

6. Скачать результат:
   - после открытия, загрузки или обработки нажмите `Скачать PLY`.

## Ограничения текущей реализации

- В браузере отображается PNG-результат серверного рендера, а не полноценная интерактивная WebGL/VTK-сцена.
- Для больших облаков preview-рендер использует равномерную выборку, чтобы не блокировать интерфейс. Полные данные сохраняются для обработки и экспорта.
- Даунсемплинг выбирает одну точку из каждого voxel. Усреднение координат и атрибутов можно добавить отдельным режимом.
- Все результаты скачиваются как PLY.
- Серверный рендеринг зависит от корректной установки VTK/OpenGL на сервере. В headless-средах может потребоваться `--use-xvfb` и системный пакет `xvfb`.
