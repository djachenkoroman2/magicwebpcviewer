Разработай web-приложение для просмотра, анализа и базовой обработки облаков точек.

## Цель
Создать локально разворачиваемое Python-приложение, которое позволяет пользователю выбирать облака точек на сервере, просматривать их в браузере, изучать свойства данных, переключать режимы визуализации и выполнять базовые операции вроде очистки, даунсемплинга, загрузки и скачивания результата.

## Основные требования
1. Приложение должно работать как серверное web-приложение.
2. Облака точек хранятся на сервере. При выборе файла для просмотра интерфейс должен давать доступ к файловой системе сервера в рамках настроенной директории с данными.
3. Нужно предусмотреть загрузку облаков точек на сервер через интерфейс.
4. Для загрузки через интерфейс добавь опциональный предварительный даунсемплинг:
   - загрузить файл полностью;
   - загрузить с даунсемплингом;
   - явно показать пользователю выбранный режим.
5. Вся тяжелая графическая обработка и рендеринг должны выполняться на сервере, где доступен GPU. Клиентский браузер должен использоваться как интерфейс управления и отображения результата.
6. Для реализации используй Python. В качестве основных библиотек можно использовать `panel` и `pyvista`.
7. Проект должен запускаться в локальном окружении `uv`.
8. Все зависимости должны быть добавлены через `uv` и зафиксированы в `pyproject.toml`.

## Поддерживаемые данные
Реализуй поддержку распространенных форматов облаков точек, если это совместимо с выбранными библиотеками:
- `.ply`;
- `.pcd`;
- `.las` / `.laz`;
- `.xyz` / `.txt`;
- другие форматы, которые естественно поддерживаются используемым стеком.

Если какой-то формат требует дополнительной зависимости или не может быть надежно поддержан, это должно быть явно описано в README.

## Интерфейс
Интерфейс должен включать:
1. Основную область просмотра облака точек.
2. Панель выбора файла с сервера.
3. Загрузку нового файла на сервер.
4. Панель свойств текущего облака:
   - имя файла;
   - формат;
   - размер файла;
   - количество точек;
   - наличие RGB-цветов;
   - список доступных scalar fields;
   - bounding box;
   - примерная плотность или другие доступные метрики, если их можно получить без дорогих вычислений.
5. Настройки визуализации:
   - отображение RGB, если RGB-данные есть;
   - однотонный режим без RGB;
   - выбор scalar field для раскраски;
   - размер точки;
   - цвет фона;
   - сброс камеры.
6. Основные операции:
   - открыть облако точек;
   - загрузить файл на сервер;
   - очистить сцену;
   - выполнить даунсемплинг;
   - скачать обработанное облако точек;
   - показать ошибки загрузки или обработки в интерфейсе.

## Даунсемплинг
Добавь минимум один способ даунсемплинга, например voxel/grid-based downsampling.

Пользователь должен иметь возможность задать параметры даунсемплинга через интерфейс. После выполнения операции приложение должно показать:
- исходное количество точек;
- итоговое количество точек;
- коэффициент уменьшения;
- возможность скачать результат.

## Архитектура и качество реализации
1. Раздели код на понятные модули:
   - загрузка и сохранение данных;
   - обработка облаков точек;
   - визуализация;
   - web-интерфейс;
   - конфигурация приложения.
2. Не смешивай всю логику в одном большом файле, если это не оправдано минимальным размером проекта.
3. Добавь обработку ошибок:
   - неподдерживаемый формат;
   - поврежденный файл;
   - слишком большой файл;
   - отсутствие GPU или невозможность серверного рендеринга;
   - пустое облако точек.
4. Для настроек путей, лимитов и параметров запуска используй конфигурацию или переменные окружения.
5. Не используй абсолютные пути, привязанные к машине разработчика.

## Критерии приемки
Результат считается готовым, если:
1. Приложение запускается через `uv`.
2. Все зависимости описаны в `pyproject.toml`.
3. Пользователь может выбрать файл облака точек из серверной директории и увидеть его в браузере.
4. Пользователь может загрузить новый файл на сервер.
5. Интерфейс показывает свойства загруженного облака точек.
6. Можно переключать RGB, однотонный режим и scalar fields, если они есть в данных.
7. Можно выполнить даунсемплинг и скачать результат.
8. README содержит полную инструкцию от установки до запуска и остановки.
9. Ошибки отображаются пользователю понятным сообщением, а не приводят к молчаливому падению приложения.

## Ограничения
Сначала реализуй надежную базовую версию приложения. Дополнительные функции добавляй только если они не усложняют основной сценарий просмотра облаков точек.
