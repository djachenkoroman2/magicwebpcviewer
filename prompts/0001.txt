1. Необходимо создать web приложение для просмотра облаков точек.
2. Облака точек расположены на сервере и при выборе файлов для просмотра должен быть доступ к файловой системе сервера.
3. Также предусмотреть возможность загрузки облака точек на сервер (Опционально либо полностью либо предварительно с опциональным даунсемплингом).
4. Вся обработка графики должна ложиться на сервер где есть GPU.
5. Для реализации приложения можно использовать python библиотеки panel и pyvista
6. В интерфейсе предусмотреть помимо области отображения облака точек и область где отображаются все свойства загруженного облака (просмотр режимов RGB или без него, опциональное отображение различных scalar field) а также основные операции такие как: загрузить облако точек, очистить, даунсемплинг, скачивание.
7. Приложение должно быть разработано на языке python в локальном окружении uv. 
8. Все дополнительные пакеты должны быть установлены в окружение uv и зафиксированы в файле project.toml
9. В файле README.md напиши все : от разворачивания окружения, установки приложения и до запуска и остановки со всеми параметрами.
